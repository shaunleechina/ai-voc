# AI VOC 智能语义分析平台

基于**上下文语义理解**的口碑数据分析平台 —— 让每一条用户声音都被精准理解。

## 项目简介

AI VOC（Voice of Customer）智能语义分析平台是面向汽车行业口碑数据的语义级分析系统。平台以"关联上下文的语义分析"为核心引擎，对用户评论文本进行深度理解，自动完成**语义归类、情感判定与结构化标注**，并输出三大代码体系（元素代码、指标代码、评价代码）的多维交叉分析视图。

与传统的"关键词匹配"方案不同，平台基于上下文语义逐句解析：同一个词在不同语境下的情感倾向会被正确区分，隐含表达（如反讽、转折、对比）也能被准确识别。

## 核心功能

- **标签分类分析**：按语义标签类型聚合全量标注数据，支持逐条钻取
- **数据分类分析**：横向表格布局，每条数据一行，含情感分布徽章、匹配类型、关键词
- **三大代码表**：元素代码表 / 指标代码表 / 评价代码表，独立三级代码体系
- **情感倾向分析**：正向褒义 / 负向贬义 / 中性 三分类统计
- **全链路钻取**：分类统计 → 标签明细 → 原始句子 → 完整原文

## 技术栈

| 层次 | 技术 |
|------|------|
| 后端 | Python Flask + Jinja2 |
| 数据库 | MySQL（连接池） |
| 前端 | 原生 JavaScript + CSS3 设计系统 |
| 服务 | Gunicorn（多 worker） |

## 快速开始

```bash
cd analysis_app
gunicorn -w 2 -b 0.0.0.0:8080 app:app --timeout 120
```

访问：http://localhost:8080
